# من أنا؟ — النسخة 22

مبنية على النسخة 21 فقط.

تغييرات الهوست فقط:
- إزالة بطاقة "إعطاء النقاط" كاملة من أسفل الصفحة.
- تصميم التنقل أصبح:
  السابق — السؤال N — التالي
  وبأسلوب قريب من المرجع المرسل.
- عند الضغط على "التالي" يظهر اختيار:
  - اسم الفريق الأول
  - اسم الفريق الثاني
  - محد جاوب
- اختيار فريق:
  يحسب نقاط السؤال تلقائيًا بنفس نظام x2 الحالي ثم ينتقل.
- "محد جاوب":
  لا يضيف نقاطًا، ويعتبر السؤال منتهيًا، ويستهلك x2 إذا كان مفعّلًا.
- السابق:
  يرجع للسؤال السابق للمراجعة.
- السؤال الذي سبق احتسابه لا يحتسب مرة ثانية عند الرجوع إليه.

لم يتم تغيير Session أو QR أو الجرس أو شاشة اللعبة أو النتائج أو الفقرات.


تعديل الهوست:
- حذف رقم السؤال العلوي.
- رقم السؤال يبقى فقط بين التالي والسابق.
- التالي يسار، السابق يمين.
